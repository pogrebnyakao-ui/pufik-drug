# Пуфик — приложение для Android

Здесь лежит Android-приложение **«Пуфик»** (в RuStore оно будет называться «Тамагочи "Пуфик"»).
Это игра-тамагочи для малышей. Внутри два слоя:

- **сама игра**: один файл `game/pufik.html`, та же игра, что и в браузере;
- **обёртка** [Capacitor](https://capacitorjs.com) 8.5.3: она превращает игру в обычное приложение для Android.

Файлы приложения (APK и AAB) собирает **GitHub Actions**. На своём компьютере ничего устанавливать не нужно.

| Что | Значение |
|---|---|
| Название на телефоне | Пуфик |
| ID приложения (пакет) | `ru.artem.pufik` |
| Версия | поле `"version"` в `package.json` (сейчас `1.0.0`) |
| Android | от 7.0 (minSdk 24); собрано под Android 16 (targetSdk 36) |
| Разрешения | только интернет (стоит в шаблоне Capacitor); игра работает и без сети |

---

## 1. Как собирается приложение

GitHub собирает приложение сам, когда:

- вы что-то меняете в ветке `main` (например, загружаете новую версию игры);
- появляется тег вида `v1.0.1`, то есть выпускается новая версия (см. раздел 4);
- вы запускаете сборку вручную: **Actions → Android → Run workflow → Run workflow**.

Где смотреть: вкладка **Actions** → сборка **Android** → нужный запуск. Сборка идёт примерно 5–10 минут.
Зелёная галочка значит, что всё получилось, красный крестик — что сборка упала (что делать, см. раздел 8).

Внизу страницы запуска, в блоке **Artifacts**, лежат готовые файлы:

| Artifact | Что внутри | Когда есть |
|---|---|---|
| `pufik-debug-apk` | `pufik-1.0.0-debug.apk`, тестовая сборка | всегда |
| `pufik-release` | `pufik-1.0.0.apk` и `pufik-1.0.0.aab`, подписанные файлы для RuStore | когда добавлен ключ подписи (раздел 3) |

Кроме того, подписанный APK каждой сборки выкладывается в пре-релиз **«Тестовая сборка»** (раздел 2).

Artifacts хранятся 90 дней и скачиваются ZIP-архивом.

## 2. Как поставить приложение на телефон

1. Проще всего открыть на телефоне постоянную ссылку на последнюю подписанную тестовую сборку:
   **https://github.com/pogrebnyakao-ui/pufik-drug/releases/download/test/pufik-test.apk**.
   Файл скачается сразу, входить в GitHub не нужно. Он обновляется после каждой сборки с ключом подписи
   (в том числе в pull request), страница с описанием — **Releases → «Тестовая сборка»**.
   В RuStore этот файл не загружайте: для магазина есть релизы `vX.Y.Z` (раздел 4).
2. Другой способ: откройте нужный запуск в **Actions**, скачайте artifact (`pufik-release`, если он есть, иначе `pufik-debug-apk`)
   и распакуйте ZIP. Внутри лежит файл `.apk`.
3. Нажмите на скачанный APK (если скачивали на компьютер, сначала перенесите его на телефон кабелем или через мессенджер).
4. Android спросит, можно ли устанавливать приложения из этого источника. Разрешите это для приложения, из которого открыли файл
   (Файлы, Telegram, Chrome). На Android 7 этот пункт называется «Неизвестные источники» в настройках безопасности.
5. Если Google Play Защита предупредит о непроверенном приложении, нажмите «Подробнее» → «Всё равно установить».

### Важно: тестовые сборки (debug) не обновляются поверх друг друга

Каждую тестовую сборку GitHub подписывает **новым случайным ключом**. Поэтому новую debug-сборку нельзя поставить поверх старой:
Android ответит «Приложение не установлено». Старую придётся удалить, а **вместе с ней удалятся питомец и рисунки**.
Так же не обновляют друг друга debug-сборка и подписанная сборка.

Чтобы не потерять питомца:

- перед удалением откройте меню родителей (шестерёнка) → «Перенос на другое устройство» → **«Показать код»** и сохраните код;
  после установки введите его там же через **«Ввести код»**;
- для настоящей игры ребёнка ставьте **подписанную сборку** (`pufik-release`). Она всегда подписана одним и тем же ключом,
  поэтому новые версии встают поверх старых, и питомец остаётся.

## 3. Ключ подписи (делается один раз)

RuStore принимает только подписанные приложения, и **все обновления должны быть подписаны тем же самым ключом**.

Claude выдаст вам две вещи: файл **`pufik-release.jks`** и **пароль** к нему. Имя ключа внутри файла — `pufik`,
у ключа тот же пароль, что и у файла.

1. **Сохраните файл и пароль надёжно, минимум в двух местах** (например, менеджер паролей и флешка или облако).
   Не загружайте файл ключа в этот репозиторий.
2. Превратите файл в текст (base64). Если Claude уже прислал готовый текст base64, пропустите этот шаг.
   - **Mac**: откройте Терминал в папке с файлом и выполните команду. Текст окажется в буфере обмена.
     ```
     base64 -i pufik-release.jks | pbcopy
     ```
   - **Windows**: откройте PowerShell в папке с файлом и выполните команду. Текст окажется в буфере обмена.
     ```
     [Convert]::ToBase64String([IO.File]::ReadAllBytes((Resolve-Path .\pufik-release.jks).Path)) | Set-Clipboard
     ```
3. На GitHub откройте репозиторий → **Settings → Secrets and variables → Actions → New repository secret** и создайте два секрета:
   - имя `KEYSTORE_BASE64`, значение — вставьте текст из буфера обмена;
   - имя `KEYSTORE_PASSWORD`, значение — пароль.
4. Запустите сборку вручную (**Actions → Android → Run workflow**). Теперь рядом с тестовой сборкой появится artifact `pufik-release`.

Секреты после сохранения не видит никто, в том числе вы сами. В журналы сборки они не попадают.

## 4. Как выпустить новую версию (для RuStore)

1. **Увеличьте версию** в `package.json`: откройте файл на GitHub → карандаш (Edit) → поменяйте строку
   `"version": "1.0.0"` → **Commit changes**.
   - Формат строго `X.Y.Z`. Например, `1.0.1` — исправление, `1.1.0` — новое в игре. Y и Z могут быть от 0 до 99.
   - **Каждая загрузка в RuStore должна иметь новую, бо́льшую версию.** Номер сборки (versionCode) считается сам:
     `1.0.0` → 10000, `1.0.1` → 10001, `1.1.0` → 10100, `2.0.0` → 20000.
2. **Создайте тег** `v` + версия, например `v1.0.1`.
   На GitHub: **Releases → Draft a new release** (или «Create a new release»). В поле выбора тега впишите `v1.0.1`
   и выберите **Create new tag** (ветка `main`). Название можно дать любое, например «Пуфик 1.0.1». Нажмите **Publish release**.
   Можно попросить и Claude: он выполнит `git tag v1.0.1` и `git push origin v1.0.1`.
3. Примерно через 10 минут GitHub Actions приложит к этому релизу файлы `pufik-1.0.1.apk` и `pufik-1.0.1.aab`
   (блок **Assets**). Их же можно скачать в artifact `pufik-release`.
4. Загрузите файл в RuStore. Обычно загружают APK, а AAB лежит рядом на случай, если RuStore попросит этот формат.

Сборка тега остановится с понятной ошибкой, если ключ подписи ещё не добавлен или тег не совпадает с версией в `package.json`.
В этом случае удалите релиз и тег (страница **Tags** → тег → Delete), исправьте причину и создайте тег снова.

## 5. Как обновить игру

1. Замените файл `game/pufik.html` новой версией с тем же именем.
   На GitHub: папка `game` → **Add file → Upload files** → перетащите файл → **Commit changes**.
2. Сборка запустится сама. Новая тестовая версия появится в Actions.
3. Чтобы обновление попало в RuStore, выпустите новую версию (раздел 4).

Требование к файлу игры: шрифт Nunito в нём подключается **одной** ссылкой Google Fonts
(`https://fonts.googleapis.com/css2?family=Nunito…`). При сборке приложения эта ссылка заменяется на шрифты,
которые лежат внутри приложения, поэтому игра работает без интернета. Если ссылки нет или их две, сборка специально
остановится с ошибкой `expected exactly one Google Fonts Nunito <link>`.

> Сейчас в репозитории лежит исходная версия игры (v7). Она запускается, но ещё ничего не знает о приложении:
> кнопку «Назад», паузу и полноэкранный режим берёт на себя версия, сделанная по договорённостям раздела 9.
> **Перед первой загрузкой в RuStore файл нужно заменить на эту версию.**

## 6. Иконка и заставка

Сейчас в приложении стоят временные иконка и заставка: оранжевый «пуфик» с глазками на кремовом фоне.
Настоящие делаются из картинок в папке `assets/`:

| Файл в `assets/` | Что это | Размер |
|---|---|---|
| `icon-only.png` | готовая иконка целиком, для старых Android | 1024×1024 |
| `icon-foreground.png` | передний слой адаптивной иконки: персонаж на прозрачном фоне | 1024×1024 |
| `icon-background.png` | задний слой адаптивной иконки: фон без прозрачности | 1024×1024 |
| `splash.png` | заставка при запуске; главное — в центре | 2732×2732 |
| `splash-dark.png` | заставка для тёмной темы (может совпадать с `splash.png`) | 2732×2732 |

Края иконки телефон обрезает кругом или скруглённым квадратом, поэтому персонаж должен стоять по центру, с полями.

Потом в папке репозитория выполняется команда (её запустит Claude):

```
npx @capacitor/assets@3.0.5 generate --android
```

Она перезапишет картинки в `android/app/src/main/res/` (`mipmap-*`, `drawable*`). Эти файлы нужно закоммитить.
На Android 12 и новее система показывает при запуске иконку приложения на фоне `#fff4c9`, а `splash.png` видят
только Android 7–11.

## 7. Чего нельзя менять никогда

1. **ID приложения `ru.artem.pufik`** — после первой загрузки в RuStore. По нему RuStore узнаёт приложение:
   с другим ID это будет другое приложение, и обновления до детей не дойдут. До первой загрузки ID ещё можно поменять,
   но сразу во всех местах:
   - `capacitor.config.json` → `"appId"`;
   - `android/app/build.gradle` → `namespace` и `applicationId`;
   - `android/app/src/main/java/ru/artem/pufik/MainActivity.java` → первая строка `package ru.artem.pufik;`
     и сами папки `ru/artem/pufik` в этом пути;
   - `android/app/src/main/res/values/strings.xml` → `package_name` и `custom_url_scheme`;
   - `android/app/src/main/assets/capacitor.config.json` — этот файл создаётся сам командой `npx cap sync`
     из `capacitor.config.json` и в git не хранится.
2. **Ключ подписи** (`pufik-release.jks`, имя `pufik`, пароль). Приложение с другим ключом не встаёт поверх старого:
   если ключ потерять или заменить, обновлять игру будет нечем, и детям пришлось бы удалять её вместе с питомцем.
   Храните две копии.
3. **Адрес игры внутри приложения `https://localhost`** (`"androidScheme": "https"` и `"hostname": "localhost"`
   в `capacitor.config.json`). Питомец и рисунки хранятся в памяти браузера (localStorage), а она привязана к этому адресу.
   Если его поменять, у всех детей после обновления игра начнётся заново, с яйца.
   По той же причине в игре нельзя переименовывать ключи сохранений `pufik.save.v1` и `pufik.art.v1`.

## 8. Если сборка упала

Откройте красный запуск в Actions. Вверху страницы будет сообщение об ошибке, а в журнале — красный шаг.
Частые случаи:

| Сообщение | Что сделать |
|---|---|
| «Нет ключа подписи» (на теге) | добавить секреты из раздела 3, удалить тег и создать снова |
| «Тег не совпадает с версией» | тег должен быть `v` + версия из `package.json` |
| «Неверный KEYSTORE_BASE64» или «Ключ не открывается» | создать секреты заново (раздел 3) |
| `expected exactly one Google Fonts Nunito <link>` | в новом файле игры нет ссылки на шрифт (раздел 5) |
| `package.json "version" must look like 1.2.3` | версия должна быть ровно `X.Y.Z`, например `1.0.1` |

В остальных случаях перешлите ссылку на запуск Claude.

## 9. Технические детали (для разработчика)

### Структура

```
game/pufik.html                 игра (обычно меняется только она)
scripts/build-web.mjs           собирает www/ из игры: обёртка приложения + локальные шрифты (договорённость A)
package.json, package-lock.json версия приложения, точные версии Capacitor 8.5.3 и @fontsource/nunito 5.3.0
capacitor.config.json           appId, appName, webDir, https://localhost, SystemBars
assets/                         исходники иконки и заставки для @capacitor/assets
android/                        Android-проект (шаблон Capacitor 8.5.3 + правки ниже)
  app/build.gradle              версия из package.json, подпись из переменных окружения
  app/src/main/java/ru/artem/pufik/MainActivity.java   нативная часть
  app/src/main/res/             иконки, заставка, тема, правила бэкапа
  variables.gradle              minSdk / compileSdk / targetSdk (как в шаблоне)
.github/workflows/android.yml   сборка в GitHub Actions
docs/                           сайт на GitHub Pages (политика конфиденциальности)
store/                          материалы для RuStore
```

Не хранятся в git и создаются заново: `node_modules/`, `www/`, `android/app/src/main/assets/public/`,
`android/app/src/main/assets/capacitor.config.json`, `android/capacitor-cordova-android-plugins/`, результаты сборки.

### Команды

```
npm ci                                  # инструменты точно по package-lock.json
npm run build:web                       # www/ из game/pufik.html
npm run sync                            # build:web + npx cap sync android
cd android && ./gradlew assembleDebug   # нужны JDK 21 и Android SDK
```

Подпись release-сборки задаётся переменными окружения `PUFIK_KEYSTORE_FILE`, `PUFIK_KEYSTORE_PASSWORD`,
`PUFIK_KEY_ALIAS` и `PUFIK_KEY_PASSWORD`. Нужны все четыре: без них release собирается неподписанным,
а если задана только часть, сборка падает. `minifyEnabled false`, debug-сборка как в шаблоне.

### Версии

- Capacitor 8.5.3 (`@capacitor/cli`, `core`, `android`), Node 22, JDK 21 (Temurin), AGP 8.13.0, Gradle 8.14.3.
- minSdk 24 (Android 7.0), compileSdk 36, targetSdk 36 (Android 16) — значения шаблона Capacitor 8.5.3.
- `versionName` = `version` из `package.json`, `versionCode` = major·10000 + minor·100 + patch.
- Эмодзи игра рисует системным шрифтом. Самые новые из них — Emoji 14.0 (🫧, 🫙): полностью они видны с Android 13.
  Emoji 13.0 (🪰, 🪆, 🪥) нужен Android 11, Emoji 12.0 (🪁, 🪀) — Android 10. На более старых телефонах эти
  несколько значков будут пустыми квадратиками. Остальные эмодзи игры есть с Android 9 и раньше.

### Договорённости игры и приложения (A–E)

**A. Обёртка.** `www/index.html` = строка ниже + файл игры, в котором ссылка Google Fonts
`<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Nunito…">` заменена на
`<link rel="stylesheet" href="fonts/nunito.css">`:

```
<!doctype html><html lang="ru"><meta charset="utf-8"><meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover"><script>window.PUFIK_APP={platform:"android"};</script>
```

В `www/fonts/` лежит Nunito 700/800/900 (latin, latin-ext, cyrillic, cyrillic-ext, woff2) из `@fontsource/nunito`
и `nunito.css` с `unicode-range`, как у fontsource. Веб-обёртка для тестов — та же строка без скрипта `PUFIK_APP`
и со ссылкой Google Fonts.

**B. Режим приложения** (`window.PUFIK_APP` задан): игра не вызывает `requestFullscreen` / `exitFullscreen`
и `navigator.wakeLock`, не останавливается по `fullscreenchange`, подсказка на стартовой карточке не упоминает
полный экран и Esc (подсказка про шестерёнку остаётся), в меню родителей скрыт переключатель отладки.
Полный экран и неотключение экрана делает само приложение. В браузере всё как раньше.

**C. `window.pufikApp = { back, pause, resume }`** (в обоих режимах), каждый вызов безопасен в любой момент:

- `back()` → `true`, если закрыто меню или окно родителей или идёт игра (жест «Назад» игнорируется,
  малыши задевают его случайно); `false` на стартовой карточке.
- `pause()`: сразу сохранить игру, приостановить звук, отпустить перетаскивание.
- `resume()`: вернуть звук, если игра идёт, и обработать долгую паузу так же, как после скрытой вкладки.

**D. Вызовы из Java** идут через `WebView.evaluateJavascript`: `(window.pufikApp&&window.pufikApp.back())===true`
(ответ — строка `"true"` или `"false"`), `window.pufikApp&&window.pufikApp.pause()`,
`window.pufikApp&&window.pufikApp.resume()`.

**E. В обоих режимах** при `visibilitychange` → hidden звук (Web Audio) приостанавливается, а когда игра снова видна,
возобновляется (если нужен жест — на следующем касании).

### Нативная часть (`MainActivity.java`)

- Полноэкранный режим: системные панели скрыты (`WindowInsetsControllerCompat`, `BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`),
  режим включается заново в `onResume` и `onWindowFocusChanged(true)`.
- **Вырезы и панели — один механизм.** Обработка отступов в Capacitor отключена (`SystemBars.insetsHandling: "disable"`
  в `capacitor.config.json`). Родитель WebView получает отступ на видимые системные панели, вырез камеры и клавиатуру,
  этот отступ залит цветом `#fff4c9`. Сам WebView получает нулевые отступы, поэтому CSS `env(safe-area-inset-*)` = 0,
  и ничего не сдвигается дважды. Так работает на всех версиях Android, включая обязательный edge-to-edge
  на Android 15/16. До Android 15 видимые панели и вырез обходит сама система, и обработчик видит нули.
- `FLAG_KEEP_SCREEN_ON`; кнопки громкости управляют звуком игры (`STREAM_MUSIC`).
- Телефоны (smallest width < 600dp) — только портрет, планшеты — любой поворот. При повороте activity не пересоздаётся
  (`configChanges` из шаблона).
- «Назад» (`OnBackPressedDispatcher`, работает и с predictive back): спрашивает `pufikApp.back()`; если ответ не `true`,
  вызывается `moveTaskToBack(true)` — приложение уходит в фон, но не закрывается. Своего обработчика «Назад»
  у Capacitor 8.5.3 нет (плагин `@capacitor/app` не подключён).
- `onPause` → `pufikApp.pause()`, `onResume` → `pufikApp.resume()`.
- WebView: `textZoom` 100 (крупный системный шрифт не ломает вёрстку), overscroll выключен.
- Тема: светлая, фон окна и заставки `#fff4c9`; заставка Android 12+ — иконка приложения на этом фоне.
- Бэкап выключен: `allowBackup="false"`, а `data_extraction_rules.xml` и `backup_rules.xml` исключают всё
  (облако и перенос со старого телефона на новый). Для переноса в игре есть свой код.
- Разрешения: только `INTERNET` из шаблона. Переключатель «Вибрация» в меню родителей в приложении поэтому
  ничего не делает: WebView вибрирует только при разрешении `android.permission.VIBRATE`. Оно выдаётся без запроса
  пользователю, но появится в списке разрешений RuStore. Добавляется одной строкой в `AndroidManifest.xml`, если нужно.

### Сборка в GitHub Actions (`.github/workflows/android.yml`)

Node 22 (кэш npm) → `npm ci` → `npm run build:web` → `npx cap sync android` → JDK 21 Temurin → setup-gradle
(проверяет gradle-wrapper.jar) → `./gradlew assembleDebug` → artifact `pufik-debug-apk`.
Если есть секреты: ключ декодируется во временную папку раннера и проверяется `keytool` →
`./gradlew assembleRelease bundleRelease` (имя ключа `pufik`, пароль ключа = пароль хранилища) →
проверка подписи `apksigner verify --print-certs` (самые новые build-tools) и `jarsigner -verify` для AAB →
artifact `pufik-release`. На теге `v*` без секретов сборка останавливается с ошибкой; с секретами создаётся
GitHub Release с APK и AAB (`gh release create`). Файл ключа удаляется в конце в любом случае.
