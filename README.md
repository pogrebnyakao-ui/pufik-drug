# Пуфик — мой питомец: приложение для Android

Здесь лежит Android-приложение **«Пуфик — мой питомец»**. Так оно называется и на телефоне под иконкой, и в RuStore:
по правилам RuStore эти названия должны совпадать.
Это игра для малышей про виртуального питомца. Внутри два слоя:

- **сама игра**: один файл `game/pufik.html`, та же игра, что и в браузере;
- **обёртка** [Capacitor](https://capacitorjs.com) 8.5.3: она превращает игру в обычное приложение для Android.

Файлы приложения (APK и AAB) собирает **GitHub Actions**. На своём компьютере ничего устанавливать не нужно.

| Что | Значение |
|---|---|
| Название на телефоне и в RuStore | Пуфик — мой питомец |
| ID приложения (пакет) | `ru.artem.pufik` |
| Версия | поле `"version"` в `package.json` (сейчас `1.0.0`) |
| Android | от 7.0 (minSdk 24); собрано под Android 16 (targetSdk 36) |
| Встроенный браузер телефона (WebView) | версия 108 или новее; на более старом вместо игры открывается страница «как обновить» (раздел 9) |
| Разрешения | интернет (стоит в шаблоне Capacitor; игра работает и без сети) и вибрация |
| Возрастная категория | 0+ (знак стоит на стартовой карточке игры) |
| Разработчик | Артем, pogrebnyakao@gmail.com; в игре: меню родителей → «О приложении» |

---

## 1. Как собирается приложение

GitHub собирает приложение сам, когда:

- вы что-то меняете в ветке `main` (например, загружаете новую версию игры);
- появляется тег вида `v1.0.1`, то есть выпускается новая версия (см. раздел 4);
- вы запускаете сборку вручную: **Actions → Android → Run workflow → Run workflow**.

Где смотреть: вкладка **Actions** → сборка **Android** → нужный запуск. Сборка идёт примерно 5–10 минут.
Зелёная галочка значит, что всё получилось, красный крестик — что сборка упала (что делать, см. раздел 8).

Внизу страницы запуска, в блоке **Artifacts**, лежат готовые файлы:

| Artifact | Что внутри | Когда есть |
|---|---|---|
| `pufik-debug-apk` | `pufik-1.0.0-debug.apk`, тестовая сборка | всегда |
| `pufik-release` | `pufik-1.0.0.apk` и `pufik-1.0.0.aab`, подписанные файлы; в RuStore загружается APK (раздел 4) | когда добавлен ключ подписи (раздел 3) |

Кроме того, подписанный APK каждой сборки выкладывается в пре-релиз **«Тестовая сборка»** (раздел 2).

Artifacts хранятся 90 дней и скачиваются ZIP-архивом.

## 2. Как поставить приложение на телефон

1. Проще всего открыть на телефоне постоянную ссылку на последнюю подписанную тестовую сборку:
   **https://github.com/pogrebnyakao-ui/pufik-drug/releases/download/test/pufik-test.apk**.
   Файл скачается сразу, входить в GitHub не нужно. Он обновляется после каждой сборки с ключом подписи
   (в том числе в pull request), страница с описанием — **Releases → «Тестовая сборка»**.
   В RuStore этот файл не загружайте: для магазина есть релизы `vX.Y.Z` (раздел 4).
2. Другой способ: откройте нужный запуск в **Actions**, скачайте artifact (`pufik-release`, если он есть, иначе `pufik-debug-apk`)
   и распакуйте ZIP. Внутри лежит файл `.apk`.
3. Нажмите на скачанный APK (если скачивали на компьютер, сначала перенесите его на телефон кабелем или через мессенджер).
4. Android спросит, можно ли устанавливать приложения из этого источника. Разрешите это для приложения, из которого открыли файл
   (Файлы, Telegram, Chrome). На Android 7 этот пункт называется «Неизвестные источники» в настройках безопасности.
5. Если Google Play Защита предупредит о непроверенном приложении, нажмите «Подробнее» → «Всё равно установить».

Если вместо игры открылась страница со словами «Игра не может запуститься…», на телефоне устарел встроенный браузер
«Android System WebView» (на Android 7–9 его роль играет Chrome). Обновите его в Google Play, закройте игру совсем
(смахните из списка недавних приложений) и откройте снова. Подробности — в разделе 9, «Старый WebView».

### Важно: тестовые сборки (debug) не обновляются поверх друг друга

Каждую тестовую сборку GitHub подписывает **новым случайным ключом**. Поэтому новую debug-сборку нельзя поставить поверх старой:
Android ответит «Приложение не установлено». Старую придётся удалить, а **вместе с ней удалятся питомец и рисунки**.
Так же не обновляют друг друга debug-сборка и подписанная сборка.

Чтобы не потерять питомца:

- перед удалением откройте меню родителей (шестерёнка) → «Перенос на другое устройство» → **«Показать код»** и сохраните код;
  после установки введите его там же через **«Ввести код»**;
- для настоящей игры ребёнка ставьте **подписанную сборку** (`pufik-release`). Она всегда подписана одним и тем же ключом,
  поэтому новые версии встают поверх старых, и питомец остаётся.

## 3. Ключ подписи (делается один раз)

RuStore принимает только подписанные приложения, и **все обновления должны быть подписаны тем же самым ключом**.

Claude выдаст вам две вещи: файл **`pufik-release.jks`** и **пароль** к нему. Имя ключа внутри файла — `pufik`,
у ключа тот же пароль, что и у файла.

1. **Сохраните файл и пароль надёжно, минимум в двух местах** (например, менеджер паролей и флешка или облако).
   Не загружайте файл ключа в этот репозиторий.
2. Превратите файл в текст (base64). Если Claude уже прислал готовый текст base64, пропустите этот шаг.
   - **Mac**: откройте Терминал в папке с файлом и выполните команду. Текст окажется в буфере обмена.
     ```
     base64 -i pufik-release.jks | pbcopy
     ```
   - **Windows**: откройте PowerShell в папке с файлом и выполните команду. Текст окажется в буфере обмена.
     ```
     [Convert]::ToBase64String([IO.File]::ReadAllBytes((Resolve-Path .\pufik-release.jks).Path)) | Set-Clipboard
     ```
3. На GitHub откройте репозиторий → **Settings → Secrets and variables → Actions → New repository secret** и создайте два секрета:
   - имя `KEYSTORE_BASE64`, значение — вставьте текст из буфера обмена;
   - имя `KEYSTORE_PASSWORD`, значение — пароль.
4. Запустите сборку вручную (**Actions → Android → Run workflow**). Теперь рядом с тестовой сборкой появится artifact `pufik-release`.

Секреты после сохранения не видит никто, в том числе вы сами. В журналы сборки они не попадают.

## 4. Как выпустить новую версию (для RuStore)

1. **Увеличьте версию** в `package.json`: откройте файл на GitHub → карандаш (Edit) → поменяйте строку
   `"version": "1.0.0"` → **Commit changes**.
   - Формат строго `X.Y.Z`. Например, `1.0.1` — исправление, `1.1.0` — новое в игре. Y и Z могут быть от 0 до 99.
   - **Каждая загрузка в RuStore должна иметь новую, бо́льшую версию.** Номер сборки (versionCode) считается сам:
     `1.0.0` → 10000, `1.0.1` → 10001, `1.1.0` → 10100, `2.0.0` → 20000.
2. **Создайте тег** `v` + версия, например `v1.0.1`.
   На GitHub: **Releases → Draft a new release** (или «Create a new release»). В поле выбора тега впишите `v1.0.1`
   и выберите **Create new tag** (ветка `main`). Название можно дать любое, например «Пуфик 1.0.1». Нажмите **Publish release**.
   Можно попросить и Claude: он выполнит `git tag v1.0.1` и `git push origin v1.0.1`.
3. Примерно через 10 минут GitHub Actions приложит к этому релизу файлы `pufik-1.0.1.apk` и `pufik-1.0.1.aab`
   (блок **Assets**). Их же можно скачать в artifact `pufik-release`.
4. Загрузите в RuStore файл **`pufik-1.0.1.apk`** (подробнее — ниже, «Загрузка в RuStore»).

Сборка тега остановится с понятной ошибкой, если ключ подписи ещё не добавлен или тег не совпадает с версией в `package.json`.
В этом случае удалите релиз и тег (страница **Tags** → тег → Delete), исправьте причину и создайте тег снова.

### Политика конфиденциальности на GitHub Pages (один раз, до первой загрузки)

Политика лежит в репозитории, в файле `docs/privacy.html`. Чтобы она открывалась по постоянному адресу:

1. На GitHub откройте репозиторий → **Settings → Pages**.
2. В блоке **Build and deployment**: **Source** — **Deploy from a branch**, **Branch** — `main` и папка `/docs` → **Save**.
3. Через пару минут проверьте, что открывается **https://pogrebnyakao-ui.github.io/pufik-drug/privacy.html**.

Этот же адрес записан в `package.json` (`"pufik"` → `"privacyUrl"`), и игра показывает его в меню родителей → «О приложении».
Если адрес когда-нибудь поменяется, исправьте его там и выпустите новую версию. Если игра когда-нибудь начнёт что-то
собирать или отправлять, политику (и короткий текст в «О приложении») нужно переписать до выпуска такой версии.

### Загрузка в RuStore

- Загружайте **APK** из релиза `vX.Y.Z`: файл `pufik-X.Y.Z.apk` из блока **Assets** (или из artifact `pufik-release` той же сборки).
- **AAB не загружайте.** Чтобы принять AAB, RuStore требует передать ему закрытый ключ подписи (зашифрованный утилитой PEPK).
  С APK ключ остаётся только у вас. Тестовую сборку `pufik-test.apk` и debug-сборки тоже не загружайте.
- **У каждой загрузки должен быть новый, больший versionCode**, то есть новая версия в `package.json` (шаг 1).
  Файл с тем же или меньшим номером RuStore не примет. Если загруженный файл нужно заменить, выпустите следующую версию.
- Название в карточке — ровно **«Пуфик — мой питомец»**, как под иконкой на телефоне. Если название когда-нибудь поменяется,
  менять его нужно и в приложении (раздел 9, «Название и данные разработчика»), и в карточке, иначе модерация отклонит версию.
- Что ещё указать в карточке:
  - возрастная категория **0+** (знак «0+» уже есть в игре);
  - тип «Игра», категория «Детские», без второй категории;
  - контакт для пользователей: e-mail **pogrebnyakao@gmail.com** (он будет виден всем);
  - политика конфиденциальности: **https://pogrebnyakao-ui.github.io/pufik-drug/privacy.html**. Если отдельного поля для неё
    в консоли нет, укажите адрес в контактах, в поле «Веб сайт»;
  - «Безопасность данных»: ничего не отмечайте. Игра ничего не собирает и не передаёт, а оба её разрешения
    (интернет и вибрация) RuStore относит к безопасным. Если консоль всё же покажет служебное разрешение
    `ru.artem.pufik.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` (раздел 9), текст для поля «Обоснование» есть в `store/listing-ru.md`;
  - в описании не должно быть ссылок: для приложений для маленьких детей RuStore это запрещает.
- Иконка в карточке должна совпадать с иконкой на телефоне (раздел 6).

## 5. Как обновить игру

1. Замените файл `game/pufik.html` новой версией с тем же именем.
   На GitHub: папка `game` → **Add file → Upload files** → перетащите файл → **Commit changes**.
2. Сборка запустится сама. Новая тестовая версия появится в Actions.
3. Чтобы обновление попало в RuStore, выпустите новую версию (раздел 4).

Требования к файлу игры:

- шрифт Nunito в нём подключается **одной** ссылкой Google Fonts
  (`https://fonts.googleapis.com/css2?family=Nunito…`). При сборке приложения эта ссылка заменяется на шрифты,
  которые лежат внутри приложения, поэтому игра работает без интернета. Если ссылки нет или их две, сборка специально
  остановится с ошибкой `expected exactly one Google Fonts Nunito <link>`;
- игра соблюдает договорённости раздела 9 (A–G): режим приложения, «Назад», пауза, «О приложении», знак 0+, шрифт эмодзи.
  Файл без них тоже соберётся, но в приложении «Назад» будет сразу сворачивать игру, а знака 0+ и «О приложении» не будет;
- если в новой версии игры появился эмодзи, которого нет во встроенном шрифте эмодзи, сборка не падает, но пишет
  предупреждение `WARNING: game/pufik.html uses … emoji that fonts/PufikEmoji.ttf lacks`, а на странице запуска
  в Actions появляется жёлтое предупреждение «Шрифт эмодзи». Тогда шрифт нужно сделать заново
  (раздел 9, договорённость G; это сделает Claude), иначе на старых телефонах такой значок будет пустым квадратиком.

## 6. Иконка и заставка

Иконку и заставку рисует сама игра: подросший Пуфик (стадия «подрос») с радостной мордочкой нарисован функцией игры `drawPet()`
на тёплом фоне из цветов игры (от `#fff6ea` в центре через `#fff4c9` к `#ffd9a8` по краям).
Исходные картинки лежат в папке `assets/`:

| Файл в `assets/` | Что это | Размер |
|---|---|---|
| `icon-only.png` | готовая иконка целиком, для старых Android | 1024×1024 |
| `icon-foreground.png` | передний слой адаптивной иконки: персонаж на прозрачном фоне | 1024×1024 |
| `icon-background.png` | задний слой адаптивной иконки: фон без прозрачности | 1024×1024 |
| `splash.png` | заставка при запуске; Пуфик маленький, в центре, фон `#fff4c9` | 2732×2732 |
| `splash-dark.png` | заставка для тёмной темы (совпадает с `splash.png`) | 2732×2732 |

Края иконки телефон обрезает кругом или скруглённым квадратом, поэтому персонаж стоит по центру, с полями:
он занимает центральные 66 % картинки.

Если картинки в `assets/` поменялись, в папке репозитория выполняется команда (её запустит Claude):

```
npx @capacitor/assets@3.0.5 generate --android --iconBackgroundColor '#fff4c9' --iconBackgroundColorDark '#fff4c9' --splashBackgroundColor '#fff4c9' --splashBackgroundColorDark '#fff4c9'
```

Она перезапишет картинки в `android/app/src/main/res/` (`mipmap-*`, `drawable*`). Эти файлы нужно закоммитить.
Ещё она переписывает оформление `AndroidManifest.xml` (смысл не меняется), его нужно вернуть:
`git checkout -- android/app/src/main/AndroidManifest.xml`.
На Android 12 и новее система показывает при запуске иконку приложения на фоне `#fff4c9`, а `splash.png` видят
только Android 7–11. Там картинка растягивается на весь экран, поэтому на вытянутых телефонах Пуфик на ней
немного выше и уже, чем на самом деле.

Иконка для карточки RuStore — `store/icon-512.png` (512×512, PNG), сделана из той же картинки: RuStore проверяет,
что она совпадает с иконкой на телефоне, и требует фон на всю площадь, без прозрачных краёв.

## 7. Чего нельзя менять никогда

1. **ID приложения `ru.artem.pufik`** — после первой загрузки в RuStore. По нему RuStore узнаёт приложение:
   с другим ID это будет другое приложение, и обновления до детей не дойдут. До первой загрузки ID ещё можно поменять,
   но сразу во всех местах:
   - `capacitor.config.json` → `"appId"`;
   - `android/app/build.gradle` → `namespace` и `applicationId`;
   - `android/app/src/main/java/ru/artem/pufik/MainActivity.java` → первая строка `package ru.artem.pufik;`
     и сами папки `ru/artem/pufik` в этом пути;
   - `android/app/src/main/res/values/strings.xml` → `package_name` и `custom_url_scheme`;
   - `android/app/src/main/assets/capacitor.config.json` — этот файл создаётся сам командой `npx cap sync`
     из `capacitor.config.json` и в git не хранится.
2. **Ключ подписи** (`pufik-release.jks`, имя `pufik`, пароль). Приложение с другим ключом не встаёт поверх старого:
   если ключ потерять или заменить, обновлять игру будет нечем, и детям пришлось бы удалять её вместе с питомцем.
   Храните две копии.
3. **Адрес игры внутри приложения `https://localhost`** (`"androidScheme": "https"` и `"hostname": "localhost"`
   в `capacitor.config.json`). Питомец и рисунки хранятся в памяти браузера (localStorage), а она привязана к этому адресу.
   Если его поменять, у всех детей после обновления игра начнётся заново, с яйца.
   По той же причине в игре нельзя переименовывать ключи сохранений `pufik.save.v1` и `pufik.art.v1`.

## 8. Если сборка упала

Откройте красный запуск в Actions. Вверху страницы будет сообщение об ошибке, а в журнале — красный шаг.
Частые случаи:

| Сообщение | Что сделать |
|---|---|
| «Нет ключа подписи» (на теге) | добавить секреты из раздела 3, удалить тег и создать снова |
| «Тег не совпадает с версией» | тег должен быть `v` + версия из `package.json` |
| «Неверный KEYSTORE_BASE64» или «Ключ не открывается» | создать секреты заново (раздел 3) |
| `expected exactly one Google Fonts Nunito <link>` | в новом файле игры нет ссылки на шрифт (раздел 5) |
| `package.json "version" must look like 1.2.3` | версия должна быть ровно `X.Y.Z`, например `1.0.1` |
| `package.json "pufik.…" must be a non-empty string` | в разделе `"pufik"` файла `package.json` пустое значение или не текст (раздел 9, F) |
| `fonts/… not found. Run scripts/subset-emoji.py` | в папке `fonts/` не хватает файла шрифта эмодзи: вернуть его из истории git или попросить Claude сделать шрифт заново |
| `www/webview-update.html is missing` | пропала страница «обновите WebView»: вернуть `web-extra/webview-update.html` из истории git (раздел 9, «Старый WebView») |

Предупреждение `WARNING: … emoji that fonts/PufikEmoji.ttf lacks` (на странице запуска — «Шрифт эмодзи») сборку
не останавливает (см. раздел 5).
В остальных случаях перешлите ссылку на запуск Claude.

## 9. Технические детали (для разработчика)

### Структура

```
game/pufik.html                 игра (обычно меняется только она)
```

### Договорённости игры и приложения (A–G)

**A. Обёртка.** `www/index.html` = строка ниже + файл игры, в котором ссылка Google Fonts
`<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Nunito…">` заменена на
`<link rel="stylesheet" href="fonts/nunito.css">`:

```
<!doctype html><html lang="ru"><meta charset="utf-8"><meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover"><script>window.PUFIK_APP={…};</script>
```

`{…}` — JSON из `package.json` (договорённость F); `<` в нём записан как `\u003c`, чтобы текст не мог закрыть `<script>`.
В `www/fonts/` лежат Nunito 700/800/900 (latin, latin-ext, cyrillic, cyrillic-ext, woff2) из `@fontsource/nunito`,
`nunito.css` с `unicode-range`, как у fontsource, и `PufikEmoji.ttf` (договорённость G, его `@font-face` тоже в `nunito.css`),
рядом лицензии обоих шрифтов. Все файлы из `web-extra/`, кроме начинающихся с точки, копируются в корень `www/` как есть
(заменить созданный сборкой файл они не могут). Веб-обёртка для тестов — та же строка без скрипта `PUFIK_APP`
и со ссылкой Google Fonts.

**B. Режим приложения** (`window.PUFIK_APP` задан): игра не вызывает `requestFullscreen` / `exitFullscreen`
и `navigator.wakeLock`, не останавливается по `fullscreenchange`, подсказка на стартовой карточке не упоминает
полный экран и Esc (подсказка про шестерёнку остаётся), в меню родителей скрыт переключатель отладки.
Полный экран и неотключение экрана делает само приложение. В браузере всё как раньше.

**C. `window.pufikApp = { back, pause, resume }`** (в обоих режимах), каждый вызов безопасен в любой момент:

- `back()` → `true`, если закрыто меню или окно родителей или идёт игра (жест «Назад» игнорируется,
  малыши задевают его случайно); `false` на стартовой карточке.
- `pause()`: сразу сохранить игру, приостановить звук, отпустить перетаскивание.
- `resume()`: вернуть звук, если игра идёт, и обработать долгую паузу так же, как после скрытой вкладки.

**D. Вызовы из Java** идут через `WebView.evaluateJavascript`: `(window.pufikApp&&window.pufikApp.back())===true`
(ответ — строка `"true"` или `"false"`), `window.pufikApp&&window.pufikApp.pause()`,
`window.pufikApp&&window.pufikApp.resume()`.

**E. В обоих режимах** при `visibilitychange` → hidden звук (Web Audio) приостанавливается, а когда игра снова видна,
возобновляется (если нужен жест — на следующем касании).

**F. `window.PUFIK_APP`, «О приложении» и знак 0+.** Сборка пишет в `PUFIK_APP`:

```
{"platform":"android","version":"1.0.0","appName":"Пуфик — мой питомец","developer":"Артем","email":"pogrebnyakao@gmail.com","privacyUrl":"https://pogrebnyakao-ui.github.io/pufik-drug/privacy.html"}
```

`version` берётся из `"version"` в `package.json`, остальное — из раздела `"pufik"` там же. Если раздела `"pufik"` нет,
`appName` = «Пуфик», а остальных полей нет. Пустое значение или не текст — ошибка сборки, незнакомый ключ — предупреждение.
Только в приложении игра показывает:

- маленький знак «0+» на стартовой карточке: знак информационной продукции, его требует соглашение с RuStore (п. 4.6);
- в меню родителей (за шестерёнкой и примером) раздел «О приложении»: название, версия, разработчик, e-mail,
  «Возрастная категория: 0+», текст «Игра не собирает и никуда не передаёт данные. Питомец и рисунки хранятся только
  на этом устройстве и удаляются вместе с приложением. В игре нет рекламы и покупок.», адрес политики конфиденциальности
  и строка о лицензиях шрифтов (Nunito и Noto Color Emoji — SIL Open Font License 1.1). E-mail и адрес — обычный текст,
  его можно выделить и скопировать; ссылок нет, потому что ссылка увела бы WebView со страницы игры или открыла другое
  приложение. Строка, для которой в `PUFIK_APP` нет поля, не показывается; без полей ничего не ломается.

В браузере ни знака, ни раздела нет.

**G. Шрифт эмодзи.** `fonts/PufikEmoji.ttf` — Noto Color Emoji 2.047 (растровая версия CBDT/CBLC, SIL Open Font
License 1.1, текст лицензии — `fonts/OFL-NotoColorEmoji.txt`), урезанный до эмодзи игры плюс U+200D и U+20E3;
вариантный селектор U+FE0F работает через сохранённую таблицу cmap (формат 14), а таблица GSUB сохранена, поэтому
составные эмодзи тоже работают. `fonts/PufikEmoji.json` записывает, из какого файла
сделан шрифт и какие символы в нём есть. Оба файла делает `scripts/subset-emoji.py` (Python 3.8+ и fontTools, как запускать —
в начале скрипта); версия COLRv1 (`Noto-COLRv1.ttf`) не годится: старые WebView её не рисуют. В режиме приложения
игра рисует эмодзи этим шрифтом (и на холсте, и в кнопках) и загружает его заранее; в браузере шрифт не используется.
`npm run build:web` сравнивает эмодзи игры со списком в `PufikEmoji.json`. Если какого-то нет, сборка не падает, но пишет
предупреждение `WARNING: game/pufik.html uses … emoji that fonts/PufikEmoji.ttf lacks` (в GitHub Actions ещё и аннотацию
`::warning` «Шрифт эмодзи», её видно на странице запуска и в `gh run view`): тогда запустите
`scripts/subset-emoji.py` заново и закоммитьте `fonts/`.

### Нативная часть (`MainActivity.java`)

- Полноэкранный режим: системные панели скрыты (`WindowInsetsControllerCompat`, `BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`),
  режим включается заново в `onResume` и `onWindowFocusChanged(true)`.
- **Вырезы и панели — один механизм.** Обработка отступов в Capacitor отключена (`SystemBars.insetsHandling: "disable"`
  в `capacitor.config.json`). Родитель WebView получает отступ на видимые системные панели, вырез камеры и клавиатуру,
  этот отступ залит цветом `#fff4c9`. Сам WebView получает нулевые отступы, поэтому CSS `env(safe-area-inset-*)` = 0,
  и ничего не сдвигается дважды. Так работает на всех версиях Android, включая обязательный edge-to-edge
  на Android 15/16. До Android 15 видимые панели и вырез обходит сама система, и обработчик видит нули.
- `FLAG_KEEP_SCREEN_ON`; кнопки громкости управляют звуком игры (`STREAM_MUSIC`).
- Телефоны (smallest width < 600dp) — только портрет, планшеты — любой поворот. При повороте activity не пересоздаётся
  (`configChanges` из шаблона).
- «Назад» (`OnBackPressedDispatcher`, работает и с predictive back): спрашивает `pufikApp.back()`; если ответ не `true`,
  вызывается `moveTaskToBack(true)` — приложение уходит в фон, но не закрывается. Своего обработчика «Назад»
  у Capacitor 8.5.3 нет (плагин `@capacitor/app` не подключён).
- `onPause` → `pufikApp.pause()`, `onResume` → `pufikApp.resume()`.
- WebView: `textZoom` 100 (крупный системный шрифт не ломает вёрстку), overscroll выключен.
- Тема: светлая, фон окна и заставки `#fff4c9`; заставка Android 12+ — иконка приложения на этом фоне.
- Бэкап выключен: `allowBackup="false"`, а `data_extraction_rules.xml` и `backup_rules.xml` исключают всё
  (облако и перенос со старого телефона на новый). Для переноса в игре есть свой код.
- Разрешения: `INTERNET` из шаблона и `VIBRATE`. Без `VIBRATE` WebView молча не вибрирует, а игра вызывает
  `navigator.vibrate` при касаниях, если в меню родителей включена «Вибрация». Оба разрешения обычные (normal):
  выдаются при установке без вопросов, RuStore относит их к безопасным.
  В итоговый манифест androidx.core добавляет ещё `ru.artem.pufik.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` уровня signature:
  без него `ContextCompat.registerReceiver(..., RECEIVER_NOT_EXPORTED)` на Android ниже 13 падает, поэтому его не убирают.
  RuStore относит signature к чувствительным; обоснование для консоли — в `store/listing-ru.md`.
- `android.webkit.WebView.MetricsOptOut` в манифесте: системный WebView не отправляет из приложения метрики,
  даже если пользователь разрешил их для Android.

### Старый WebView: проверка при запуске и страница-заглушка

Игру показывает системный WebView (Chromium). Обычно он обновляется через Google Play («Android System WebView»,
на Android 7–9 эту роль играет браузер Chrome), но на телефоне без обновлений может быть старым. В `capacitor.config.json`:

```
"server": { …, "errorPath": "webview-update.html" },
"android": { "minWebViewVersion": 108 }
```

Как это устроено в Capacitor 8.5.3 (`node_modules/@capacitor/android/capacitor/src/main/java/com/getcapacitor/`):

- Проверка идёт один раз, когда создаётся activity (`Bridge.loadWebView`): старшая цифра версии WebView сравнивается
  с `minWebViewVersion`. Если она меньше и задан `errorPath`, WebView открывает `https://localhost/webview-update.html`
  вместо игры (без `errorPath` игра запустилась бы как есть, с одной строкой в logcat). После обновления WebView игру
  нужно закрыть и открыть снова.
- Android 8 и новее: версия берётся у того WebView, который реально работает (`WebView.getCurrentWebViewPackage()`,
  первое число в `versionName`): на Android 8–9 обычно это Chrome, с Android 10 — Android System WebView, у некоторых
  производителей — свой. Для `com.huawei.webview` (Huawei без сервисов Google) у Huawei своя нумерация, и Capacitor
  сравнивает её с отдельным порогом `android.minHuaweiWebViewVersion` (по умолчанию 10): на таких телефонах заглушка
  практически не появляется, а игра может открыться и в WebView на Chromium ниже 108 (для этого у меню родителей
  есть запасная высота, см. ниже).
- Android 7: берётся версия Chrome (`com.android.chrome`), если он есть на телефоне (включён ли он, Capacitor
  не проверяет); если Chrome нет — `com.android.webview`, затем Amazon `com.amazon.webview.chromium`. Пакет Google
  `com.google.android.webview` на Android 7 не проверяется: без Chrome там будет заглушка, даже если WebView свежий.
- `errorPath` — путь от корня `www/`, без `/` в начале. Ту же страницу Capacitor открывает, если не загрузилась
  сама страница игры (`BridgeWebViewClient.onReceivedError` и `onReceivedHttpError` для основного документа);
  у нас так может быть только при сломанной сборке.
- Файл обязателен: если `www/webview-update.html` нет, ответ 404 снова открывает `errorPath`, и старый WebView
  бесконечно перезагружает страницу. Поэтому `web-extra/webview-update.html` не переименовывайте и не удаляйте.
  `npm run build:web` проверяет, что файл из `errorPath` попал в `www/`, и без него останавливается с ошибкой.

Сама страница — `web-extra/webview-update.html`: только HTML и CSS, без скриптов, ссылок и внешних файлов, чтобы
открыться в любом старом WebView. «Назад» на ней убирает приложение в фон, как на стартовой карточке.

Почему 108 — что из нового использует игра (версии Chromium):

| Что | С версии | Без этого |
|---|---|---|
| `?.` (optional chaining) в скриптах | 80 | скрипты не разбираются, игра не запускается |
| `100dvh` в высоте меню родителей (`.sheet`) | 108 | в приложении меню берёт запасную высоту `100vh` (см. ниже); в браузере меню не прокручивается: на телефоне не видно его начала и конца, в том числе «Готово» |
| `inset: 0` | 87 | стартовая карточка прижата к верху экрана |
| `gap` во flex-рядах | 84 | кнопки в меню родителей стоят вплотную |
| `:focus-visible`, `accent-color`, `outline` по скруглению, `text-wrap: balance` | 86, 93, 94, 114 | только внешний вид |
| остальное: Canvas 2D, Path2D, Web Audio, Pointer Events, async/await, CSS Grid, `min()` / `max()` / `clamp()`, `overflow-wrap: anywhere` | 80 и новее | — |

Запасная высота меню уже стоит в игре, только для приложения:
`@supports not (height: 1dvh) { html.app .sheet { max-height: calc(100vh - 32px); } }`. В WebView `100vh` и `100dvh` —
одно и то же: адресной строки, которая меняла бы высоту, у него нет. Нужна она прежде всего телефонам Huawei, где Capacitor
не сравнивает версию Chromium (см. выше); в браузере это правило не действует. Порог 108 оставлен как версия, с которой
всё работает как задумано; опустить его (по таблице — до 80) можно после проверки игры на таком старом WebView.

### Сборка в GitHub Actions (`.github/workflows/android.yml`)

Node 22 (кэш npm) → `npm ci` → `npm run build:web` → `npx cap sync android` → JDK 21 Temurin → setup-gradle
(проверяет gradle-wrapper.jar) → `./gradlew assembleDebug` → artifact `pufik-debug-apk`.
Если есть секреты: ключ декодируется во временную папку раннера и проверяется `keytool` →
`./gradlew assembleRelease bundleRelease` (имя ключа `pufik`, пароль ключа = пароль хранилища) →
проверка подписи `apksigner verify --print-certs` (самые новые build-tools) и `jarsigner -verify` для AAB →
artifact `pufik-release`. С секретами, если это не тег, APK выкладывается в pre-release `test` как `pufik-test.apk`
(файл и описание заменяются, тег `test` переносится на этот коммит). На теге `v*` без секретов сборка останавливается
с ошибкой; с секретами создаётся GitHub Release с APK и AAB (`gh release create`), а если он уже есть, файлы в нём
заменяются (`--clobber`). Файл ключа удаляется в конце в любом случае.
