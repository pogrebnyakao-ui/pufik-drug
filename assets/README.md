# Исходники иконки и заставки

Сюда кладутся картинки, из которых `@capacitor/assets` делает иконки и заставку Android
(подробно — в README.md в корне, раздел «Иконка и заставка»):

- `icon-only.png` — иконка целиком, 1024×1024
- `icon-foreground.png` — передний слой адаптивной иконки (прозрачный фон), 1024×1024
- `icon-background.png` — задний слой адаптивной иконки (без прозрачности), 1024×1024
- `splash.png` — заставка, 2732×2732, главное по центру
- `splash-dark.png` — заставка для тёмной темы, 2732×2732

Генерация (из корня репозитория), потом закоммитить изменения в `android/app/src/main/res/`:

```
npx @capacitor/assets@3.0.5 generate --android
```
