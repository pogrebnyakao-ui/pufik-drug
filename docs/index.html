Пуфик — мой питомец

Пушистый питомец для малышей: покормить, искупать, поиграть, порисовать и уложить спать.

  • Без рекламы и покупок.
  • Работает без интернета.
  • Не собирает и не передаёт данные: всё хранится только на устройстве.
  • Для родителей: лимит времени в день, время сна и меню, закрытое от малыша.
